宇辰导航 - 简洁美观的个人导航页
一个功能完整、支持个性化设置的现代化导航网站，支持自定义网址、深色模式、实时时间与天气，纯前端实现，开箱即用。
✨ 功能亮点
🕒 实时时间显示：秒级刷新，展示完整日期与星期
🌤️ 自动定位天气：根据 IP 获取城市，实时展示温度与天气
🔍 多引擎搜索：支持百度、搜狗、必应一键切换搜索
⚙️ 个性化网址：可自由添加、编辑、删除导航卡片
🎨 主题切换：支持浅色 / 深色模式自动切换
📝 字体大小调节：小 / 中 / 大三档适配
📱 响应式布局：完美适配电脑、平板、手机
💾 本地存储：所有配置自动保存，刷新不丢失
🚀 快速使用
直接下载 / 克隆本仓库
打开 index.html 即可运行使用
支持部署到 GitHub Pages / Netlify / Vercel 等静态平台

🎯 使用说明
1. 搜索功能
点击顶部搜索引擎可切换平台
输入关键词按回车或点击搜索图标即可跳转
2. 网址管理
点击 添加网址 按钮创建自定义卡片
鼠标悬浮卡片上显示编辑 / 删除按钮
支持设置图标、背景色、网站名称与链接
3. 个性化设置
点击右下角 ⚙️ 图标打开设置面板
可切换浅色 / 深色模式
调节三种字体大小
所有设置自动保存到本地

开放天气 API + IP 定位
